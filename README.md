# 糧線守衛：放逐騎士的黎明 — 手機瀏覽器試玩版

一關濃縮版：第一章第 1～4 關的內容濃縮成一關，用來展示核心循環（白天建設 → 黃昏佈防 → 夜晚死守 → 黎明事件）、糧食補給線，以及失敗後的 Roguelike 機制。

## 如何執行
不需要建置步驟，純 HTML5 Canvas + JavaScript，沒有用到任何外部函式庫。

- **直接開啟**：用瀏覽器打開 `index.html`（file:// 可正常執行）。
- **手機上玩（建議）**：在資料夾內啟動靜態伺服器，再用手機連同一個 Wi-Fi 開啟：
  ```
  python3 -m http.server 8000
  # 手機開 http://<電腦IP>:8000/
  ```
- **除錯模式**：網址加上 `?debug=1`，速度按鈕可切到 4x／8x；主控台可使用 `__game`（例如 `__game.give()`、`__game.skip()`、`__game.forceEnd(true)`）。
  Phase 1 新增：`__game.boss()`（立刻召喚首領格魯姆，含登場演出）、`__game.xp(n)`（給英雄經驗）、`__game.evolve()`（直接進化）、`__game.supply('rear'|'east'|'front')`、`__game.branch(塔位, 'ranger'…)`、`__game.beacon()`、`__game.sfx()`（音效狀態）、`__game.talents()`。

## 操作
- 點地圖空地：移動英雄
- 點路邊的石台：蓋塔（第一下預覽射程，再點一下才建造），或升級／賣出已經蓋好的塔；Lv3 的塔可選分支（永久）
- 開局選補給站位置（越前線＝越多塔吃得到糧，但掠奪者越多）；白天點補給站可花 40 木遷移
- 夜晚底部中間按鈕變成「烽火」（每夜一次，花前線糧換 10 秒攻速）；右上「敵情」顯示下一波
- 英雄 Lv10 時左下出現金色「進化」按鈕；選英雄畫面左下「天賦樹」
- 點後方虛線空地（白天才能蓋）：農田／伐木場／採石場／房屋
- 右下技能鈕 → 再點地圖：施放英雄技能
- 底部中間按鈕：提早進入黃昏或夜晚；左下角切換遊戲速度
- 地圖左上：靜音、暫停（暫停選單：繼續／設定／敵人圖鑑／重新開始／返回地圖）；切到背景會自動暫停
- 電腦鍵盤：空白鍵跳到下一個階段，Q 鍵施放技能，Esc／P 暫停

## 美術素材
正式美術圖放在 `assets/`，都是透明背景的 PNG，由 `tools/extract_art.py` 從概念圖裁切出來。它會偵測不是背景的連通區域、去掉背景和腳下陰影，再用最近鄰縮放。單位圖的上方 75% 保留灰色暗面，最下面 25% 才去掉地面陰影。素材清單在 `js/art_manifest.js`（自動產生，記錄尺寸和腳底錨點）。

- **已換成正式圖**：
  - 三位英雄的遊戲小人，每人 4 格：待機、走路、攻擊、技能。走路時待機和走路兩格交替。
  - 英雄選擇畫面的立繪。
  - 敵人：哥布林步兵、狼騎兵、盾兵、蝙蝠、掠奪者。
  - 4 種防禦塔，Lv1／Lv2／Lv3 分別用原圖第 1、2、4 欄。
  - 建築：城堡、農田、伐木場、採石場、房屋、糧倉、補給站。
  - 補給馬車：去程往右上，回程往左下，馬頭會跟著行進方向轉。
  - 村民依工作換圖：農田用農夫、伐木場用伐木工、採石場用石匠，搬運時用扛袋工人。
  - 兵營士兵：平常是待機，攻擊時切換成刺擊；Lv3 兵營改用騎士。
  - 地圖裝飾：松樹、橡樹、灌木、岩石。背景以 2 倍解析度預先畫好，每幀只貼一張圖。
  - 塔位石台，以及頂部的資源圖示（木頭、石頭、麥束、糧車、村民頭像）。
- **仍是暫代點陣圖**：城堡血量的愛心圖示（來源圖裡沒有）。
- **已裁好但遊戲還沒用到**：`arsonist`（縱火狂）、`sapper`（地鼠工兵）、`boss`（酋長格魯姆）。

**對應方式**：`js/sprites.js` 裡的 `SPRITE_OVERRIDES` 把遊戲裡的素材 key 對應到正式圖。對應值可以是一個字串，也可以是變體物件，例如 `{ idle, walk, attack, skill }` 或 `{ 1, 2, 3 }`。正式圖沒有載入成功時，會自動退回暫代圖。
PNG 存的是「邏輯尺寸 × 2」，畫面上用 0.5 倍畫出來。

**換新圖的方法**：把 PNG 放進 `assets/`，在 `js/art_manifest.js` 加一筆資料（填 `src`、`w`、`h`，`ax`／`ay` 是腳底位置），再到 `SPRITE_OVERRIDES` 指過去就好。
如果要重新裁切，執行 `python tools/extract_art.py`（需要 Pillow、numpy、scipy），裡面的來源路徑請依實際位置修改。

## 英雄（八方旅人風 Q 版）與光影
- 遊戲中的英雄圖改用第二版八方旅人風 Q 版（頭身約 1:2）：每位英雄 正面／側面／背面 站姿 + 側面動作 6 格（走 A、走 B、攻擊預備、攻擊出手、技能預備、技能出手），由 `tools/extract_heroes_oct.py` 切出（同一英雄所有影格同比例、同腳底基準，約 38 邏輯像素高）。特效（綠箭光、金色劍弧／速度線、魔法陣、魔彈、火球）切成獨立的 `*_fx_*` 圖，以加亮方式疊在角色前後。底部英雄按鈕用正面站姿；英雄選擇卡維持原本立繪。
  - 若重跑 `tools/extract_art.py`，之後要再跑一次 `tools/extract_heroes_oct.py`（它會移除舊英雄影格並寫入新影格到 `js/art_manifest.js`）。
- 動作（`js/heroanim.js`，只影響畫面，不改遊戲邏輯／時間／傷害，邏輯座標不動）：
  - 四方向走路循環（`assets/*_wf*`、`*_wb*`、`*_ws*`，來自 3×4 走路圖）：正面、背面各 4 格；側面艾琳／蕾娜 3 格（來回 1-2-3-2），薇拉 4 格；側面一律存成朝右，向左＝鏡像。每格約 0.12–0.16 秒、依實際移動速度調整；踏地格壓扁＋小彈跳、過渡格彈高、左右輕擺、踏地揚塵。停下時回到同方向站姿；待機每 0.5 秒呼吸一次。
  - 方向判斷：取移動速度（平滑後）的主軸，另一軸需大 1.35 倍且至少維持 0.12 秒才轉向，斜走不會閃爍。
  - 捨棄的格：艾琳側面第 4 格（身體轉向鏡頭）、蕾娜側面第 4 格（其實是正面）。蕾娜背面走路圖左右翻轉，讓劍和背面站姿在同一側。
  - 蕾娜：後仰 0.15 秒 → 衝刺 0.1 秒（殘影）→ 出手（金色劍弧、頓格 0.05 秒、敵人閃白＋小擊退）→ 跳回原位 0.2 秒。預備動作利用攻擊冷卻倒數提前播放，出手影格剛好對上實際傷害的那一刻；目標中途死亡就直接收回。
  - 艾琳：後跳半步＋拉弓 → 放箭（披風揚起、箭頭綠光）；薇拉：腳下小魔法陣詠唱 0.3 秒 → 出手射出魔彈。
  - 技能：箭雨（朝天射出 → 箭落下）、聖盾衝鋒（盾後蹲伏 → 金色速度線衝刺＋殘影）、隕石術（大魔法陣、畫面微暗、火球隕石落下）。
- 光影（`js/lighting.js`）：每個英雄影格都有對應的邊緣光；腳下投影（批次繪製、略過畫面外與受擊閃白單位）、暖色邊緣光、夜晚英雄色光圈、技能／投射物加亮光暈。
- 效能：背景依畫布像素預先縮放一次後每幀 1:1 貼上；投影使用裝置像素快取圖；夜色遮罩用 180×320 小畫布最近鄰放大。

- `tools/layout_guide.png`（`tools/make_layout_guide.py`）是同尺寸的平塗版面參考圖。

## 背景音樂（原創）
- `assets/audio/`：`day`（白天，G 大調 88 BPM，87.3 秒循環）、`night`（夜戰，D 小調 160 BPM，72 秒循環）、`dusk`（黃昏提示 5.9 秒）、`victory`、`defeat`（約 6–7 秒），各有 OGG 與 MP3（瀏覽器不支援 OGG 時自動改用 MP3）。
- 由 `tools/music/compose.py` 產生：以 Python 寫出 MIDI（旋律、和聲、低音、打擊樂皆為原創）→ FluidSynth＋FluidR3_GM 音色庫合成（含殘響）→ 殘響尾巴疊回開頭做成無縫循環 → 響度 -16 LUFS、峰值 ≤ -1.5 dBFS。改旋律／和弦後重跑即可；MIDI 檔也在同一資料夾。
- 遊戲中：白天／黃昏／黎明播白天曲，夜晚切到夜戰曲（1.5 秒交叉淡化）；進入黃昏播提示音、結算播勝利／失敗短曲。手機需先點一下畫面才會出聲（第一次點擊時解鎖）。
- 音量在 `js/config.js` 的 `MUSIC_VOLUME`、`STING_VOLUME`、`MUSIC_FADE`。靜音按鈕：選英雄畫面右上角、遊戲中地圖左上角（設定會記住）。
- 以 file:// 開啟時用 `<audio>` 的音量淡入淡出；http(s) 下改走 Web Audio 增益（iOS 才能調音量）。

## 技能演出（cut-in）
- 施放技能時：畫面變暗 → 英雄色斜帶（艾琳綠、蕾娜紅金、薇拉紫）掃入 → 全身立繪從右側滑入（速度線、殘影）→ 停留並顯示技能名 → 滑出，共 1.1 秒；立繪滑出時技能才真正發動（與原本相同的效果與數值）。點擊畫面可略過。伴隨合成的風切音效（`assets/audio/whoosh.*`，受靜音控制）。
- `js/config.js`：`SKILL_CUTIN`（開關）、`CUTIN_SLOW`（演出期間遊戲時間倍率；預設 0 = 暫停，背景使用快照不重畫，效能最好；設 0.2 則為慢動作並持續重畫場景）、`SFX_VOLUME`。
- 立繪：`assets/{id}_cutin.webp`（載入失敗時改用 .png），由 `tools/make_cutins.py` 以 rembg 去背（艾琳、蕾娜用 isnet-anime；薇拉用 isnet-general-use 去掉地板與書堆、法杖頂端補回 isnet-anime 結果），並清理碎片、去除邊緣背景色。蕾娜保留戰馬。圖片在開場時預先載入並依畫布解析度預先縮放。

## Phase 2：第一章 10 關＋進化美術（v6）
- **流程**：標題 → 關卡地圖（第一章・邊境森林，10 個節點、星數、鎖定／開放、最佳成績）→ 關卡卡片（簡介、敵軍、可用塔、挑戰條件開關）→ 英雄選擇 → 遊戲。結算畫面有「下一關」。
- **10 關**（`tools/levels_def.py` → `js/levels.js`）：1 初到領地（2 夜，只有弓箭塔，沒有補給線）、2 兵營之路（峽谷隘口）、3 狼嚎之夜、4 補給的開始（第一次選補給站）、5 雙路進攻（左右兩條路，敵情標示左路／右路）、6 盾牆（法師塔）、7 暗夜掠奪（兩側掠奪者）、8 蝙蝠之谷（蝙蝠、縱火狂、砲塔解鎖）、9 斷橋河谷（河流、斷橋、地鼠工兵）、10 酋長格魯姆（雙路、第 5 夜首領）。每關各自的路線、塔位、建地、補給站選項、波次、開放的塔／建築、起始資源。分支升級從第 5 關開放、烽火從第 4 關開放。
- **縱火狂**：從側面森林進來，燒掉後方建築（停止生產）或糧倉（損失 40% 後方糧、不能交糧、車隊停運），燒 2 處後逃走；點被燒的建築花木頭修復（建築 30 木、糧倉 45 木）。
- **地鼠工兵**：在地底移動（打不到，只看得到土堆），在補給道路上鑽出挖路 4 秒（此時打得到）；挖斷後車隊過不去，最近的村民會自動去修（6 秒）。
- **挑戰條件**（關卡卡片勾選）：不准蓋兵營／最多 4 座塔／城堡血量減半／英雄不能施放技能；第一次帶條件通關額外給碎片。
- **存檔**（localStorage `lxsw_save_v1`）：各關星數、通關次數、挑戰完成、碎片、天賦、曾經進化過的英雄、英雄卡片的進化插畫切換。
- **進化美術**：進化後的 Q 版三方向站姿（`{英雄}_evo_front/side/back`，`tools/extract_evo.py`）。走路／攻擊／技能沿用原本的動作時間，但畫進化站姿加上程式擺動（走路上下彈跳＋左右搖擺、攻擊前傾、施法後仰），比把原本的動作影格調色成進化配色更像同一個角色。
  進化演出與進化後的技能演出改用**整張進化插畫（含背景）**做成金框面板從右側滑入（`{英雄}_evo_panel.jpg`）；英雄選擇卡曾進化過的英雄可切換成進化插畫（`{英雄}_evo_portrait.jpg`，`tools/make_evo_portraits.py` 從原圖裁切，不去背）。
- **平衡**：`tests/balance_levels.js`（頁面內固定步長模擬，10 關 × 3 英雄約 10 秒）；各關敵人血量倍率在 `tools/levels_def.py` 的 `HP_TUNE`；英雄經驗 `HERO_XP`／`DAWN_XP` 在 `js/config.js`。
- **效能**：夜色層的靜態光源（城堡、糧倉、補給站、塔與其暖色光暈）快取，只在配置或夜色濃度改變時重畫；動態光源（英雄、車隊、技能、爆炸）每 2 幀更新一次；塔光暈改畫進夜色層（不再每幀在主畫布 lighter 疊加）。
- **除錯**：`__game.start(英雄, 祝福, 補給站, 關卡, 挑戰)`、`__game.level()`、`__game.progress()`、`__game.spawn(種類, 路線)`；第 0 關＝第 1 階段原始試玩關（回歸測試用，不在地圖上）。
